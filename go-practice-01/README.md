# Практическая работа № 1. Знакомство с Go

Курс «Бэкенд-разработка на языке Go».

## Окружение

- Операционная система: Windows 11.
- Версия Go: go version go1.27.2 windows/amd64.
- Редактор: VS Code.

## Выполнено

Выполнены задания 1-3 и дополнительные задания

## Запуск первой программы

Откройте терминал в папке проекта, где находятся `main.go` и `go.mod`.

```text
go run .
```

## Проверка сборки и оформления

```text
go fmt ./...
go build ./...
```

## Дополнительные программы

Задание 1:

```text
go run .
```

Задание 2:

```text
go run ./cmd/experiments
```

Задание 3:

```text
go run ./cmd/time-conventer
```
Дополнительное задание:

```text
go run ./cmd/average
```

## Проверенные данные

Задание 1:

Выводит сообщение в терминал. Изменен текст сообщения.

Задание 2:

Выводит карточку с данными пользователя. Изменено имя и продолжительность.

Задание 3:

Вводится количесвто минут. Выводится количество часов и оставшиеся минуты (целочисленное деление и остаток от деления на 60).

Дополнительное задание:

Выводит среднее арифмитическое трёх значений минут. Изменено количество минут


## Что осталось сделать

Обязательные и дополнительные задания выполнены.
