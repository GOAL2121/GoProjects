## Проверенные данные

Задания:

1. Add: в Task добавляется текст задачи и ег приоритет, возвращает структуру Task в store с добавлением ID

2. Get: возвращает Task по введённому ID

3. Complete: меняет Status на "done", для задачи по введённому ID

4. Delete: удаляет задачу по ID

5. List: возвращает все задачи из store
